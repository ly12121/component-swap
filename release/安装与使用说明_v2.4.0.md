# 器件、位号与连接走线网络交换 v2.4.0

作者：LIYAN

## 新功能与修正

- 默认同步交换两个器件 `Designator` 位号丝印的 X、Y 坐标和旋转方向。
- 位号文字内容、字体、可见性和所在丝印层保持不变；不需要时可独立关闭此功能。
- 处理画布选中事件前会再次核对 PCB 实际选中集，迟到的旧事件不会再把上一对器件填回器件栏。
- 交换成功后的所有结束路径都会再次清空“器件1”和“器件2”。
- 位号、器件或走线网络任一步失败时，事务会尝试恢复全部原状态。
- 扩展图标已更换为用户提供的 288×288 JPEG 图片。

## 更新安装

1. 关闭当前“器件连续交换”窗口。
2. 打开“高级 → 扩展管理器… → 导入”。
3. 选择 `pin-to-pin-component-swap_v2.4.0.eext` 并覆盖旧版。
4. 确认版本为 `2.4.0`、作者为 `LIYAN` 且扩展已启用。
5. 完全退出嘉立创 EDA 后重新启动。

扩展 UUID 与旧版相同，导入后会直接升级。

## 使用方法

1. 打开 PCB，点击“器件连续交换 → 打开连续交换窗口...”。
2. 默认保持“同步交换位号丝印”勾选。
3. 需要同步走线网络时，保持“交换对应引脚连接的走线网络”勾选。
4. 在 PCB 画布依次点击器件1和器件2；第二个器件选中后立即交换，无需确认。
5. 成功后两个器件槽位立即显示“未选择”，可继续点击下一对。
6. 每次交换后运行 DRC，并检查飞线、网络类、差分对和等长约束。

## 位号丝印范围

只修改两个器件关联的 `Designator` 属性图元：

- 交换 X 坐标；
- 交换 Y 坐标；
- 交换旋转角度。

不会互换位号文字、字体、字号、显隐状态、镜像状态或丝印层。缺少位号属性或位号已锁定时，会在移动器件前停止；也可以关闭位号同步后继续。

## 走线网络范围

只修改从两个器件对应焊盘中心实际连通的直线、圆弧和过孔网络。不修改 PCB 网表、器件引脚、其它器件、覆铜、填充、独立焊盘或同名但没有物理连通的铜图元。
