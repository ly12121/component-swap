# 器件交换 v2.4.2

作者：LIYAN

## 本次更新

- 扩展显示名称改为“器件交换”，内部唯一标识符和 UUID 保持不变，可直接覆盖升级。
- 使用新的浅蓝色简约图标：两颗金黄色芯片配合蓝色双向交换箭头，直观表示器件互换功能。
- 图标规范为 512×512 PNG；扩展交换逻辑与 v2.4.1 保持一致。

## 更新安装

1. 关闭当前交换窗口。
2. 打开“高级 → 扩展管理器… → 导入”。
3. 选择 `pin-to-pin-component-swap_v2.4.2.eext` 并覆盖旧版。
4. 确认扩展名称为“器件交换”、版本为 `2.4.2`、作者为 `LIYAN`，且扩展已启用。
5. 完全退出嘉立创 EDA 后重新启动。

## 使用方法

1. 打开 PCB，点击“器件交换 → 打开连续交换窗口...”。
2. 默认保持“同步交换位号丝印”勾选。
3. 需要同步走线网络时，保持“交换对应引脚连接的走线网络”勾选。
4. 在 PCB 画布依次点击器件1和器件2；第二个器件选中后立即交换，无需确认。
5. 成功后两个器件槽位立即显示“未选择”，可继续点击下一对。
6. 每次交换后运行 DRC，并检查飞线、网络类、差分对和等长约束。

## 修改范围

- 器件：互换中心 X、Y 坐标和旋转角度。
- 位号丝印：仅互换两个器件 `Designator` 的 X、Y 坐标和旋转角度。
- 走线网络：仅修改从对应焊盘中心实际连通的直线、圆弧和过孔网络。
- 不修改 PCB 网表、其它器件引脚、覆铜、填充或同名但未连通的铜图元。
