# 器件位置、方向与连接走线网络交换 v2.3.2

## 本次调整

- 扩展清单已配置 Gitee 源代码仓库、项目主页和问题反馈地址。
- 源代码仓库：<https://gitee.com/li-yan-123/jlc_extend>
- 两个器件交换提交成功后，窗口中的“器件1”和“器件2”列表立即清空。
- PCB 选中状态和延迟画布事件仍在后台安全清理，不会把上一轮器件带入下一轮。
- 网络同步范围保持为“被交换器件引脚实际连接的走线链”。
- 不读取或写入 PCB 网表，也不按网络名称扫描全板。
- 不修改其它器件引脚、独立焊盘、覆铜、填充、折线或同名但没有物理连通的铜图元。

## 更新安装

1. 关闭当前“器件连续交换”窗口。
2. 在嘉立创 EDA 专业版中进入“高级 → 扩展管理器… → 导入”。
3. 选择 `pin-to-pin-component-swap_v2.3.2.eext` 并覆盖旧版。
4. 确认“已安装”列表显示版本 `2.3.2` 且扩展已启用。
5. 完全退出嘉立创 EDA 后重新启动。

扩展 UUID 与旧版相同，导入后会升级原扩展。

## 使用方法

1. 打开 PCB，点击“器件连续交换 → 打开连续交换窗口...”。
2. 保持“交换对应引脚连接的走线网络”勾选。
3. 在 PCB 画布依次选择器件1和器件2。
4. 选择第二个器件后立即交换两者中心位置、旋转方向和对应引脚连接走线的网络，不需要确认。
5. 交换成功后器件1、器件2列表立即显示“未选择”；后台清理完成后即可继续选择下一对。

只想交换位置和方向时，请在选择第二个器件之前取消勾选网络选项；此时允许不同封装和不同焊盘数量。

## 走线修改范围

会修改：

- 从对应器件焊盘中心直接接出的直线或圆弧；
- 与上述走线物理相邻并连通的后续直线、圆弧；
- 该连通走线链中的过孔。

不会修改：

- PCB 网表和原理图；
- 两个被交换器件以及其它器件的引脚网络；
- 同名但与这些焊盘没有物理连通的走线；
- 独立焊盘、覆铜、填充、折线及其它 PCB 图元。

## 安全条件与限制

- 开启走线网络同步时，两器件的焊盘编号集合必须完全一致。
- 连接走线的当前网络必须与起始器件焊盘一致。
- 连接走线不能锁定。
- 同一条物理走线不能同时被要求改成两个不同网络。
- 任一检查或提交失败时，扩展会尝试恢复走线网络及两个器件的原位置和方向。

按当前要求，走线链另一端连接的其它器件引脚不会改变。因此交换后可能出现远端引脚与走线网络不一致，这是限定修改范围后的必然结果。正式工程请先保留副本，并在每次交换后运行 DRC，检查飞线、网络类、差分对和等长约束。
